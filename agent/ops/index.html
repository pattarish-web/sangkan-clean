จะรู้ได้ยังไงว่ามี AI จอง

1. เปิดกล่อง info@sangkanclean.com หาเมลหัวข้อ «คำขอจากเอเจนต์» — เป็นข้อความภาษาคน มีรหัสงาน บริการ ราคา ชื่อเอเจนต์ และเบอร์ลูกค้า ไม่ใช่ไฟล์ JSON

2. ไลน์ไม่ยิงเข้าแชทร้านเอง — หลังจองระบบเปิดแชท @sangkanclean ให้ ต้องกดส่งในไลน์ ร้านถึงจะเห็นในกล่อง @sangkanclean

3. รายการด้านล่างเป็นคิวทดลองในเบราว์เซอร์เครื่องนี้เท่านั้น ไม่ใช่กล่องกลางของทั้งบริษัท
