01

ให้เอเจนต์หาเจอ
llms.txt ชุดเอเจนต์, markdown twin, JSON-LD และ sitemap เฉพาะชั้นนี้ — ไม่แตะ /llms.txt หรือ sitemap.xml ของเว็บคน

02

แคตตาล็อกและราคา
เปิดบริการ + สูตรราคาเดียวกับ script.js บนเว็บคน รวมขั้นต่ำทั่วไป ฿3,500 และหลังก่อสร้าง ฿8,000

03

จองจากเอเจนต์
ส่งคำขอได้รหัสงาน SK-… เมล/ไลน์เป็นภาษาคน หัวข้อ «คำขอจากเอเจนต์» — คิวบน /agent/ops เป็นเครื่องทดลอง ไม่ใช่กล่องกลาง

04

ทักษะที่เรียกได้
Agent Card, UCP, OpenAPI และ MCP ชี้มาที่ /agent — GET ใช้ได้บนเว็บจริง POST quotes/bookings ใช้เมื่อรัน Next.js
